Asistente ASUS Google

Asistente personal privado de Pedro Mendez para consultar sus cuentas autorizadas de Google desde un chat privado de Telegram, utilizando OpenClaw y GitHub Copilot.

Qué permite

Consultar correos, eventos del calendario, archivos de Drive, documentos y hojas de cálculo para responder preguntas y organizar información. La integración inicial solicita permisos de solo lectura; no envía correos ni modifica archivos o eventos.

No ofrece registro público. Cada cuenta debe autorizarse expresamente mediante Google OAuth. Publicar esta página no permite acceder al asistente ni a las cuentas.

El contenido necesario para responder puede procesarse mediante GitHub Copilot y mostrarse en Telegram. Revisá la política de privacidad antes de autorizar una cuenta.
